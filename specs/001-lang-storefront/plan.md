# Implementation plan

1. Adapt Medusa DTC Starter for Vietnam: VND, `vi-VN`, original brand configuration, seeded sample catalogue, and original page copy.
2. Build storefront surfaces: age gate, navigation, trust content, categories, product details, cart, checkout, policy pages, and neutral support language.
3. Add commerce configuration: COD/manual-transfer development payment providers, delivery zones/rates, adapter interfaces for approved payment and shipping services.
4. Add automated checks: Playwright customer-journey tests, Lighthouse budgets, dependency scanning, and staging-only DAST instructions.
5. Prepare operations: environment template, production runbook, retention/deletion process, release checklist, and merchant/carrier approval checklist.
6. Deploy only after the owner supplies hosting, database, domain, payment, carrier, and approved notification credentials.
